A Figma plugin powered by @imgly/background-removal

What it does

Select any layer with an image fill in Figma, run the plugin, and the background is cut out and replaced with a transparent PNG — without ever leaving your browser or sending your image to a server.

The result is written back into the same layer as a new image fill, so your layout stays untouched.

How it works

  1. The plugin reads the image bytes from your selected Figma layer.
  2. An ONNX-based segmentation model runs entirely in the plugin's iframe using WebAssembly — no data leaves your machine.
  3. The model isolates the foreground subject and outputs a transparent PNG.
  4. The new image is written back into the layer's fills, replacing the original.

Performance

The first run downloads and caches the model weights (~40 MB). Subsequent runs reuse the cache, so they're significantly faster. Keeping the plugin window open between runs is the best way to get near-instant results — the model stays resident in memory.

Under the hood

Background removal is handled entirely by @imgly/background-removal, an open-source package by IMG.LY. It runs the RMBG model via ONNX Runtime Web, with WebAssembly as the execution backend. No GPU required.

The plugin shell is standard Figma Plugin API — a thin TypeScript host that passes image bytes to the iframe UI and writes the result back.
